Sistem manajemen keanggotaan untuk DPW PSI Papua Pegunungan.

== Description ==
Plugin ini menyediakan sistem lengkap untuk mengelola data keanggotaan PSI Papua Pegunungan termasuk:
- Manajemen anggota (tambah, edit, hapus)
- Dashboard statistik keanggotaan
- Import data dari file CSV
- Export data ke CSV dan Excel
- Keamanan (rate limiting login, activity log, security headers)
- Integrasi WhatsApp (shortcode & floating button)
- Sistem CAPTCHA sederhana
- Pengaturan user roles khusus

== Installation ==
1. Upload folder `anggota-psi-papua-pegunungan` ke `/wp-content/plugins/`
2. Aktifkan plugin melalui menu Plugins di WordPress
3. Menu "Anggota PSI" akan muncul di sidebar admin
4. Klik "Import Data Demo" di Customizer untuk mengisi data awal
